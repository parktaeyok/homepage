기준: [2일차 콘텐츠 기획](day-02-customer-flow-and-content.md), [3일차 화면 설계](day-03-screen-design.md)

## 1. 적용 원칙

이 문서는 이후 디자인·개발에 사용할 홈페이지 문구의 기준이다. 기존 문서와 문구가 다르면 이 문서를 우선하며, 배치와 메뉴 동작은 3일차 설계를 따른다. 상단 회사명은 사용자 요청대로 왼쪽에서 16px 여백을 두고 왼쪽 정렬한다.

주 고객은 품질관리 회사와 컨설팅 기업이다. ISO 9001 및 자동차 분야 IATF 16949 관련 업무를 지원하는 QMS 맞춤 개발·운영 서비스를 소개한다. 이번 홈페이지는 서비스 소개와 상담 접수 범위이며 실제 QMS 업무 처리는 후속 개발이다.

- 회사명: **(주)인지아이앤에스**
- 메뉴: **서비스 / 주요 기능 / 구축 절차 / 회사 소개**

## 3. 첫 화면 — 공개용 문구

대상 표시: **품질관리 기업을 위한 QMS 맞춤 개발**

분야 표시: **ISO 9001 · IATF 16949**

제목:

> 품질관리 업무를 하나의 QMS로

설명:

> 고객사별 문서, 심사 일정, 부적합과 시정조치를 연결합니다.
> (주)인지아이앤에스가 귀사의 업무 흐름에 맞춰 QMS(품질경영시스템)를 설계하고 개발합니다.

버튼: **QMS 도입 상담 / 주요 기능 보기**

오른쪽 구성도 제목: **고객사별 품질 업무**

- 문서 · 검토 · 승인
- 심사 일정 · 증빙 자료
- 부적합 · 원인 분석 · 시정조치
- 대응 이력 · 진행 현황

구성도 설명: **맞춤 개발 구성 예시**

## 4. 서비스 — 공개용 문구

제목: **업무 분석부터 구축 후 운영까지**

| 서비스명 | 설명 |
| --- | --- |
| 업무 분석·시스템 설계 | 현재 사용하는 문서와 업무 절차를 살펴보고, 고객사별 관리 기준과 담당자별 처리 흐름을 설계합니다. |
| QMS 맞춤 개발·구축 | 문서, 심사 일정, 부적합 및 시정조치 등 필요한 관리 기능을 업무 우선순위에 맞춰 개발합니다. |
| 운영·유지보수 | 구축 후 사용 과정에서 필요한 수정과 기능 개선을 지원합니다. 구체적인 지원 범위는 계약 시 정합니다. |

## 5. 주요 기능 — 공개용 문구

제목: **귀사의 품질 업무에 맞춰 구성하는 관리 기능**

소개: **필요한 관리 항목과 처리 절차를 확인하고, 업무에 맞는 기능을 설계합니다.**

| 기능명 | 설명 |
| --- | --- |
| 문서·승인 관리 | 품질 문서의 개정 이력과 검토·승인 상태를 함께 확인하도록 구성합니다. |
| 심사·인증 업무 관리 | 심사 일정, 체크리스트, 증빙 자료와 후속 조치를 연결해 관리하도록 구성합니다. |
| 부적합·시정조치 관리 | 문제 등록부터 원인 분석, 개선 조치와 효과 확인까지 진행 상태를 관리하도록 구성합니다. |
| 고객사·협력사 대응 | 고객사별 요청과 대응 이력, 담당자 및 처리 기한을 정리하도록 구성합니다. |
| 고객사별 현황 관리 | 고객사별 일정과 미완료 업무, 주요 관리 항목을 한눈에 확인하도록 구성합니다. |

접수 연결 전 내부 시안 문구: **화면 설계용 · 상담 접수는 아직 연결되지 않았습니다.**

## 9. 하단과 검색 정보

하단 표시: **(주)인지아이앤에스 / 상담 전화 010-4103-1467 / 개인정보 처리방침**

개인정보 처리방침은 내용 확정 후 실제 안내 화면에 연결한다. 공개 페이지에 빈 링크나 ‘추후 작성’ 같은 내부 작업 문구를 노출하지 않는다.

- 페이지 제목: **QMS 맞춤 개발 | (주)인지아이앤에스**
- 페이지 설명: **ISO 9001·IATF 16949 관련 품질 업무를 위한 QMS 맞춤 개발. 고객사별 문서, 심사, 부적합·시정조치 관리부터 구축 후 운영까지 (주)인지아이앤에스와 상담하세요.**
- 대표 주소: 도메인 확정 후 반영.

## 11. 개인정보 운영 정보의 반영 위치

이 항목은 법률 문안이 아니라, 공개 전에 운영 담당자와 구체화할 콘텐츠 목록이다. 보관 기간이나 운영 담당자를 임의로 확정하지 않는다.

| 확인할 내용 | 반영 위치 |
| --- | --- |
| 상담 접수·회신 목적과 실제 수집 항목 | 문의 양식의 제출 버튼 위 안내, 개인정보 처리방침 |
| 필요한 동의 방식과 안내 문구 | 제출 버튼 바로 위 |
| 보관 기간과 삭제 절차 | 개인정보 처리방침 및 문의 안내 중 필요한 부분 |
| 개인정보 관련 문의 담당자·연락처 | 개인정보 처리방침 |
| 실제 사용하는 서비스와 데이터 처리 방식 | 운영 구조 확인 후 개인정보 처리방침 |

개인정보 안내와 접수 운영 방식이 준비되기 전에는 온라인 문의를 실제로 수집하지 않는다. 전화 상담 경로는 별도로 유지한다.

## 12. 문구 검토 결과와 다음 단계

- 회사명·상담 전화와 ISO 9001·IATF 16949 표기를 통일했다.
- ‘QMS’의 첫 설명에 ‘품질경영시스템’을 병기했다.
- 실제 출시 제품이 아닌 맞춤 개발 서비스를 소개하도록 표현을 정리했다.
- 근거 없는 실적, 인증 취득 보장, 고정 가격·개발 기간을 넣지 않았다.
- 회사명 왼쪽 정렬과 모바일 배치는 3일차 설계를 유지한다.
- 로고와 수행 사례가 없어도 다음 디자인 단계는 진행할 수 있다.

5일차에는 이 콘텐츠 기준안으로 색상·서체·버튼·영역별 시각 디자인을 정리한다. Next.js 개발 환경 연결과 실제 문의 접수 구현은 기존 개발 일정에서 진행한다.
