# 1일차 — QMS 개발 서비스 홈페이지 요구사항

작성일: 2026-09-23  
상태: 1일차 요구사항 정리 완료 / 세부 운영 정보는 후속 단계에서 확정

## 1. 사업 목적과 대상 고객

(주)인지아이앤에스가 품질관리 회사를 대상으로 ISO 9001 및 자동차 분야 IATF 16949 관련 업무를 지원하는 QMS(품질경영시스템)를 맞춤 개발하고, 구축 후 운영·유지보수 서비스를 소개하는 기업용 홈페이지를 만든다.

- 직접 고객: 고객사의 품질·인증 관련 업무를 수행하는 품질관리 회사 및 컨설팅 기업.
- 초기 산업 배경: 자동차 제조사와 부품 협력업체의 품질 업무. 이들 기업에 직접 판매할지, 품질관리 회사를 통해 제공할지는 추가 확인한다.
- 주요 방문자: 품질관리 회사 대표, 업무 책임자, 시스템 도입 검토 담당자.
- 홈페이지 목표: 방문자가 서비스와 구축 범위를 이해하고 상담을 요청할 수 있게 한다.
- 실제 QMS 관리 시스템은 홈페이지와 구분해 후속 단계에서 개발한다.

## 3. 메시지와 콘텐츠 기준

대표 문구 초안:

> ISO 9001 · IATF 16949 품질관리 업무를 하나의 QMS로
>
> (주)인지아이앤에스는 품질관리 기업의 업무에 맞춘 시스템을 개발해 문서, 심사, 부적합 및 시정조치를 통합 관리합니다.

설명은 소프트웨어 개발·운영 서비스에 초점을 맞춘다. 인증서 발급 기관으로 오인할 표현이나 인증 취득 보장 문구는 사용하지 않는다. 실제 출시된 제품, 구축 완료 기능, 실적, 고객사, 자격으로 확인되지 않은 내용은 사실처럼 표시하지 않는다. 관리 화면 예시는 데모로 명시한다.

아래 항목은 콘텐츠 단위다. 각각을 별도 페이지로 만들지는 2일차 화면 기획에서 결정한다.

| 콘텐츠 | 포함 내용 | 방문자가 확인할 정보 |

| 구축 절차 | 업무 분석 → 설계 → 개발 → 검증 → 교육·운영 | 도입 진행 방식 |
| 회사 소개 | 회사 정보, 전문 분야, 확인된 수행 경험 | 서비스 제공 주체 |
| 상담 문의 | 문의 양식, 확인된 연락처, 접수 결과 안내 | 도입 상담 방법 |

## 5. 소개할 QMS 기능 범위

다음은 맞춤 개발 서비스의 소개 범위이며, 1차 홈페이지에 해당 관리 기능을 구현한다는 뜻은 아니다.

| 기능군 | 소개할 업무 |
| --- | --- |
| 문서·승인 관리 | 품질 매뉴얼·절차서, 개정 이력, 검토·승인 |
| 심사·인증 업무 관리 | 심사 일정, 체크리스트, 증빙 자료, 후속 조치 |
| 부적합·시정조치 관리 | 문제 등록, 원인 분석, 개선 조치, 효과 확인 |
| 고객사·협력사 대응 | 클레임, 개선대책, 대응 이력 및 담당자 관리 |
| 고객사별 현황 | 고객사별 진행 상태, 일정, 업무 및 품질 지표 |

ISO 9001과 IATF 16949를 중점 분야로 소개한다. 표준별 세부 요구사항, 고객사 요구사항과 시스템 기능의 대응 관계는 상세 기획에서 검토한다. 특정 표준에 대한 완전한 준수나 인증 취득을 보장한다고 표현하지 않는다.

## 6. 상담 접수 요구사항 초안

- 필수 입력 제안: 회사명, 담당자명, 회신용 이메일, 문의 내용.
- 선택 입력 제안: 전화번호, 관심 기능, 희망 구축 시기.
- 홈페이지에 상담 전화 010-4103-1467을 표시하고, 모바일에서 전화 연결을 지원한다.
- 문의는 서버에서 검증한 뒤 Supabase에 저장한다.
- 일반 방문자는 다른 문의를 조회·수정·삭제할 수 없어야 한다.
- 접수 성공과 실패를 구분해 안내하고, 실패 시 작성 내용을 유지한다.
- 개인정보 수집 항목, 안내·동의 방식, 보관 기간, 삭제 담당자는 실제 운영 방식과 함께 공개 전에 확정한다.
- 접수 담당자와 조회 방법은 추후 확정한다. 별도 관리자 화면, 자동 이메일 알림, 파일 첨부는 이번 기본 범위에 포함하지 않는다.
- 연락처가 미정인 동안 임의 전화번호·이메일을 노출하거나 실제 접수처럼 보이는 가짜 성공 처리를 하지 않는다.

## 7. 1차 개발 제외 범위

- 고객사 로그인과 사용자 초대·권한 관리.
- 실제 품질 문서 업로드, 승인 흐름 및 개정 관리.
- 심사 수행, 시정조치 처리, 고객사별 실시간 대시보드.
- 결제, 전자서명, 외부 업무 시스템 연동.

위 기능은 후속 QMS 프로젝트에서 사용자 역할, 고객사별 데이터 분리, 업무 흐름을 먼저 설계한 뒤 견적과 일정을 정한다.

## 8. 홈페이지 완료 기준

- 서비스 대상과 QMS 맞춤 개발·운영 제공 범위를 첫 화면에서 이해할 수 있다.
- 휴대폰과 PC에서 내용과 메뉴가 잘리지 않고 읽힌다.
- 키보드로 메뉴와 문의 양식을 사용할 수 있고 입력 항목에 명확한 이름이 있다.
- 상담 필수 항목 검증, 저장, 성공·실패 안내가 동작한다.
- 문의 데이터와 운영용 비밀키가 일반 방문자에게 공개되지 않는다.
- 제목·설명 등 검색 노출의 기본 정보를 설정한다.
- 실제 운영 정보와 확인된 회사 자료를 반영하고, 공개 전 시험 문의로 접수 흐름을 확인한다.
- GitHub 소스 관리와 Vercel 배포가 연결되고, 운영 방법을 문서로 남긴다.
