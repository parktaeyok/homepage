# 5일차 — 시각 디자인 기준안

회사: (주)인지아이앤에스  
작성일: 2026-09-23  
상태: 디자인 기준과 전체 페이지 시안 작성 완료. 실제 홈페이지 구현 전 단계.

## 1. 디자인 방향

짙은 남색 첫 화면과 밝은 본문을 조합해 QMS 개발 서비스를 명확하게 전달한다. 본문은 선과 여백으로 정리하고, 큰 제목과 상담 버튼으로 읽는 순서를 잡는다. 확인되지 않은 실적 수치나 장식용 대시보드는 사용하지 않는다.

회사명은 PC·모바일 모두 상단 왼쪽 16px 위치를 유지한다. 기존 3일차 설계의 메뉴·방문 흐름을 유지하며, 본문 문구의 최종 기준은 [4일차 콘텐츠](day-04-content.md)다. 시안의 짧은 설명은 배치 검토용 요약이며 실제 개발 시 4일차 문구를 반영한다.

## 2. 색상

| 용도 | 밝은 화면 기준 | 적용 위치 |
| --- | --- | --- |
| 대표 남색 | #112840 | 첫 화면 배경 |
| 본문 배경 | #FFFFFF | 상단 메뉴, 서비스, 구축 절차 |
| 보조 배경 | #F2F6FB | 주요 기능, 상담 영역 |
| 기본 글자 | #13253D | 제목과 본문 |
| 설명 글자 | #506176 | 부가 설명 |
| 주요 버튼 | #205BC2 | 상단 도입 상담 버튼 |
| 첫 화면 강조 | #B6D5FF | 대상 표시, 주요 상담 버튼 |
| 첫 화면 설명 | #C5D4E8 | 남색 배경 위 설명 |
| 구분선 | #D4DEEA | 영역·행 구분 |

대화 시안은 앱의 밝은·어두운 화면 설정에 따라 대응 색상을 사용한다. 어두운 화면에서는 본문 배경 #111D2E, 기본 글자 #EDF3FA, 설명 #B4C3D5를 적용한다. 실제 사이트의 테마 전환 기능은 이번 범위에 추가하지 않는다.

## 3. 서체와 여백

- 서체: 맑은 고딕, Apple SD Gothic Neo, 시스템 산세리프 순서. 외부 폰트가 없어도 읽을 수 있게 한다.
- 회사명: PC 18px, 모바일 16px, 굵게.
- 첫 화면 제목: 화면 너비에 따라 32~52px, 줄 간격 1.25.
- 영역 제목: PC 28px, 모바일 22px, 줄 간격 1.4.
- 기능 제목: 17px. 본문·입력 글자: 16px. 라벨·보조 안내: 14px.
- 본문 줄 간격: 1.75. 한국어 제목은 단어 단위 줄바꿈을 우선한다.
- 본문 영역 여백: PC 위아래 64px·좌우 32px, 모바일 위아래 40px·좌우 20px.
- 첫 화면은 PC 위아래 72px. 불필요한 고정 높이는 두지 않는다.
- 반응형 기준: 1,024px부터 PC 메뉴, 768~1,023px 접이식 메뉴·일부 2열, 767px 이하 주요 영역 1열.

## 4. 버튼과 입력 요소

| 요소 | 디자인 기준 |
| --- | --- |
| 주요 버튼 | 파랑 배경·흰 글자. 남색 첫 화면에서는 밝은 파랑 배경·남색 글자 |
| 보조 버튼 | 주변 배경과 어울리는 바탕과 구분선 |
| 공통 크기 | 높이 최소 48px, 좌우 여백 20px, 글자 16px |
| 모서리 | 기본 4px. 시안에서 0~12px를 비교할 수 있음 |
| 입력창 | 글자 16px, 높이 최소 44px, 항상 보이는 항목 라벨 |
| 비활성화 | 보조 배경·설명 글자색과 연결 전 문구로 상태 구분 |
| 키보드 초점 | 브라우저 초점 표시 유지 |

## 5. 영역별 적용

1. 상단: 회사명 왼쪽, 메뉴와 도입 상담 오른쪽. 모바일에서는 메뉴 버튼으로 전환한다.
2. 첫 화면: 왼쪽에 큰 제목과 상담 버튼, 오른쪽에 고객사별 품질 업무 구성도를 배치한다. 구성도는 실제 관리 화면이 아닌 업무 범위 설명이다.
3. 서비스: 번호와 상단 구분선으로 3개 서비스를 구별한다.
4. 주요 기능: 옅은 배경 위에 기능명·설명을 행 단위로 정리한다.
5. 구축 절차: 01~05 번호로 순서를 표시하며 모바일은 세로로 배치한다.
6. 회사 소개: 왼쪽 강조선과 회사명으로 구분한다.
7. 상담: 안내와 전화번호 옆에 밝은 양식 영역을 배치한다. 모바일에서는 안내 다음 양식이 이어진다.
8. 하단: 회사명과 전화번호를 간결하게 표시한다. 개인정보 안내는 실제 운영 정보 확정 후 연결한다.

## 6. 시안 동작과 확인

- PC·모바일 배치와 버튼·패널 모서리를 대화 시안의 조정 기능에서 비교할 수 있다.
- 메뉴와 주요 버튼의 내부 이동 대상을 점검했고, 중복 식별자가 없음을 확인했다.
- 메뉴 스크립트의 구문 검사를 통과했다.
- 밝은 화면 주요 글자 대비를 계산했다: 본문 15.44:1, 설명 6.34:1, 주요 버튼 6.29:1, 첫 화면 설명 9.96:1.
- 위 확인은 정적 구조·구문·색상 계산이다. 실제 브라우저에서 전체 화면과 키보드 사용 흐름을 검수한 결과는 아니다.
- 문의 양식은 시안에서 비활성화되어 있다. 실제 정보 저장·전송은 수행하지 않는다.
