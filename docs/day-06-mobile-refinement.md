## 2. 화면 너비별 설계

- 320px: 작은 모바일. 본문 좌우 20px, 양식 안쪽 좌우 12px. 입력·버튼은 영역 안에서 줄바꿈한다.
- 390px: 기본 모바일 시안. 주요 영역·입력창·관심 기능을 한 열로 표시한다.
- 768px: 태블릿. 접이식 메뉴와 기존 다열 구조를 적용한다.
- 1,024px 이상: PC 메뉴와 기존 PC 배치.

시안 조정 기능에서 네 가지 너비를 선택할 수 있다. 실제 표시 가능한 너비보다 크게 강제 확대하지 않으며, 좁은 창에서는 사용 가능한 너비에 맞춘다.

## 3. 문의 상태 디자인

| 상태 | 시안에서 보여주는 내용 | 실제 구현 시 동작 |
| --- | --- | --- |
| 기본 | 연결 전 버튼과 입력 양식 | 항목 입력·선택 가능 |
| 입력 오류 | 이메일 아래 오류 설명, 오류 테두리 | 해당 항목에 오류 안내·초점 이동, 작성 내용 유지 |
| 접수 중 | 보내는 중 표시 | 중복 제출 차단, 상태 안내 |
| 성공 | 접수 완료 표시 예시 | 서버 저장 확인 후에만 성공 안내 |
| 실패 | 실패 안내와 상담 전화 | 작성 내용 유지, 다시 시도 가능 |

모든 상태 전환은 디자인 비교용이다. 성공·실패 문구에는 ‘표시 예시’를 붙이고, 성공 안내에는 ‘실제 접수 아님’을 추가했다. 입력창과 제출 버튼은 계속 비활성화 상태이며 실제 문의 내용을 수집·전송·저장하지 않는다.

입력 오류는 글자와 테두리로 함께 전달한다. 상태 안내 영역은 보조 기술이 읽을 수 있도록 설정한다. 실제 입력 검증, 중복 제출 방지, 초점 이동과 데이터 저장은 후속 개발 단계에서 구현한다.

## 4. 확인한 항목과 남은 검수

확인 완료:

- 메뉴·상태 변경 스크립트의 구문 검사.
- 내부 메뉴의 이동 대상 존재 여부와 HTML 식별자 중복 여부.
- 시안의 연결 전 표시 및 실제 접수와 구분되는 상태 안내.
- 회사명 왼쪽 정렬, 모바일 입력 글자 16px, 메뉴·선택 영역 48px 기준 반영.

아직 완료하지 않은 검수:

- 실제 브라우저에서 320·390·768·1,024px 화면을 렌더링한 시각 검수.
- 글자 200% 확대 시 겹침과 가로 넘침 확인.
- 실제 홈페이지의 키보드 초점 이동과 문의 접수 전 과정 확인.

이번 확인은 코드의 정적 구조·구문 점검이며, 브라우저 검수를 통과했다는 뜻은 아니다. 위 항목은 개발한 화면에서 확인한다.
